# Spectre has moved

This repository was the sideload set for my receive-only Wi-Fi and Bluetooth LE watcher. I shipped it as Spectre through 1.2.14. I later learned that name was already in use by another app, so I renamed this one Fieldwatch to keep the two from being mixed up.

I am not here to step on another tool. We need as many of these as we can get. Their Spectre keeps its name.

**Go here:** [OffGridPete/Fieldwatch](https://github.com/OffGridPete/Fieldwatch)

Source, MIT License, APK, instruction card, and user manual all live in that repository. Installing Fieldwatch does not replace Spectre on your phone (`app.fieldwatch` is a new app). Sideload Fieldwatch when you are ready; uninstall Spectre if you no longer need it.

Do not download an APK from this repository. Files here are frozen. New issues: [Fieldwatch issues](https://github.com/OffGridPete/Fieldwatch/issues).
